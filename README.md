# 3D Chess

Browser-based 3D chess built with React, TypeScript, Three.js / React Three Fiber, chess.js, and Lichess Board API integration.

## Public URL

https://totoro0419.github.io/3dchess/

## Development

```bash
npm install
npm run dev
npm run typecheck
npm test
npm run build
```

## Notes

- Standard chess rules are handled by chess.js.
- Live Lichess human games must not expose engine assistance.
- GitHub Pages is deployed from `main` with GitHub Actions.
